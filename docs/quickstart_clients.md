## 1. Какие ссылки выдаёт Server-Combain

Администратор сервера может в любой момент посмотреть все актуальные ссылки и QR-коды командами в SSH-терминале:
- `comb info` (или `comb info --all`) — сводка ссылок, DoH-адреса и команды PowerShell;
- `comb qr` — интерактивное меню QR-кодов прямо в консоли;
- `comb mesh` -> пункт **`5` (Пользователи и подписки)** — выдача персональных ссылок для семьи и друзей (с лимитом устройств HWID и сроком действия).

| Тип ссылки | Формат URL (пример) | Для чего подходит |
| :--- | :--- | :--- |
| **Персональная JSON-подписка (кластер)** | `https://vpn.example.com/u-json/<token>` | **Рекомендуется для `v2RayTun` и `v2rayNG`**. Включает TCP 1–1 фрагментацию (анти-ТСПУ) и 2-уровневый RU split-tunneling. |
| **Персональная Base64-подписка (кластер)** | `https://vpn.example.com/u/<token>` | Универсальный формат для `Hiddify`, `Happ`, `Streisand`, `FoXray`, `Nekoray` / `Throne`. |
| **Единая JSON-подписка (один сервер)** | `https://vpn.example.com/sub-json/<token>` | То же самое, что `/u-json/`, но для одиночного сервера без кластера `Combain-Mesh`. |
| **Единая Base64-подписка (один сервер)** | `https://vpn.example.com/sub/<token>` | Универсальная подписка одиночного сервера. |
| **Умный DNS (DoH)** | `https://dns.vpn.example.com/dns-query` | Обход геоблокировок ИИ-сервисов и зарубежных сайтов **без включения VPN**. |

> **Подсказка:** если используется режим единого домена, DoH-адрес будет выглядеть как `https://vpn.example.com/dns-query`.

## 2. Android (`v2RayTun`) — подписка, RU-обход и Per-App Bypass

**`v2RayTun`** — самый удобный и стабильный клиент для Android с полной поддержкой **VLESS Encryption**, **XHTTP**, **TCP-фрагментации** и JSON-подписок Server-Combain.

### Шаг 1. Установка и импорт подписки
1. Установите **v2RayTun** из Google Play (или официального репозитория).
2. Получите у администратора **JSON-подписку** (`https://vpn.example.com/u-json/<token>` для кластера или `https://vpn.example.com/sub-json/<token>` для одного сервера) либо отсканируйте её QR-код (администратор выводит его через `comb qr` -> пункт `1`, либо при создании пользователя в `comb mesh`).
3. В приложении нажмите **`+`** (в правом верхнем углу):
   - выберите **«Импорт из буфера обмена»** (если скопировали ссылку) или **«Сканировать QR-код»**.
4. В списке появятся все доступные узлы и протоколы (например, `🇩🇪 Combain-Direct-XHTTP [vpn.example.com]`, `🇩🇪 Combain-Direct-WS [vpn.example.com]`, IPv6- и CDN-маршруты при их настройке).
5. Нажмите на значок обновления подписки (круговые стрелки), выберите ближайший узел (обычно **Direct-XHTTP**) и нажмите большую кнопку подключения.

### Шаг 2. Как работает встроенный 2-уровневый RU Split-Tunneling
В JSON-подписку (`/u-json/<token>` и `/sub-json/<token>`) **уже встроены правила маршрутизации Xray**, которые не требуют скачивания `geosite.dat` / `geoip.dat` на телефон:

1. **Слой 1 — Блокировка RU SDK-телеметрии и IP-проб (`ru_telemetry_block.list`):**
   - Стоит **выше** правила `direct` и отправляет в `block` (blackhole) трекеры и IP-чекеры: `apptracer.ru`, `sdk-api.apptracer.ru`, `tracker-api.my.com`, `tracker-api.vk-portal.net`, `stats.vk-portal.net`, `vk-analytics.ru`, `top-fwz1.mail.ru`, `rs.mail.ru`, `report.appmetrica.yandex.net`, `startup.mobile.yandex.net`, `appmetrica.yandex.ru`, `mc.yandex.ru`, `api.ipify.org`, `ifconfig.me`, `checkip.amazonaws.com`.
   - Рабочие API **MAX** (`api.oneme.ru`, `max.ru`), **Госуслуг** и **банков** при этом **не** блокируются.
   - Этот же список применяется на уровне **AdGuard Home Smart DNS**, поэтому телеметрия режется даже при выключенном VPN.
2. **Слой 2 — Прямой обход RU-сервисов (`ru_bypass_domains.list` + локальные сети):**
   - Локальные сети (`10.0.0.0/8`, `192.168.0.0/16`, `172.16.0.0/12`, `fe80::/10` и др.), все домены зон `.ru`, `.su`, `.рф` и пресет российских сервисов (Госуслуги, MAX, VK, Сбер, Т-Банк, ВТБ, Альфа-Банк, Ozon, Wildberries, Яндекс, операторы) направляются напрямую (`outboundTag: "direct"`), минуя VPN-туннель.

**Как проверить, что RU-обход работает:**
- Включите VPN в `v2RayTun`.
- Откройте в браузере `2ip.ru` (или `yandex.ru/internet`) — должен отображаться **ваш российский IP-адрес** (трафик пошёл напрямую).
- Откройте `ifconfig.co` или `whoer.net` — должен отображаться **IP вашего зарубежного сервера** (трафик пошёл через VPN).

### Шаг 3. Настройка Per-App Bypass (Раздельное туннелирование по приложениям)

**Зачем нужен Per-App Bypass, если split-tunneling уже встроен?**
Встроенная маршрутизация Xray работает по доменам и IP, но часть российских приложений (банки, Госуслуги, MAX) проверяет в системе Android сам факт наличия активного VPN-интерфейса (`tun0`) или обращается к серверам по прямому IP без доменного имени. Если добавить такие приложения в **исключения (Per-App Bypass)**, Android пустит их трафик полностью в обход `v2RayTun`.

В связке оба механизма идеально дополняют друг друга:
- **Per-App Bypass** — скрывает наличие VPN от нативных банковских и гос-приложений;
- **2-уровневый split-tunneling** — страхует веб-версии этих сервисов в браузере и режет SDK-телеметрию.

**Как включить в `v2RayTun`:**
1. Отключите VPN (если он активен).
2. Перейдите в **Настройки** -> **Раздельное туннелирование (Per-App Proxy / Bypass Apps)**.
3. Включите режим **«Исключить выбранные приложения» (Bypass / Игнорировать выбранные)**.
4. Найдите в списке (по названию или по Package ID) и отметьте галочками нужные приложения:

| Приложение | Android Package ID | Зачем исключать |
| :--- | :--- | :--- |
| **MAX** | `ru.oneme.app` | Мессенджер и проверка локального подключения |
| **Госуслуги** | `ru.rostel` | Авторизация ЕСИА, защита от детекта VPN |
| **СберБанк Онлайн** | `ru.sberbankmobile` | Стабильная работа переводов, СБП и пушей |
| **Т-Банк (Тинькофф)** | `com.idamob.tinkoff.android` | Антифрод банка не любит зарубежные IP |
| **ВТБ Онлайн** | `ru.vtb24.mobilebanking.android` | Корректный вход и подтверждение операций |
| **Альфа-Банк** | `ru.alfabank.mobile.android` | Корректная работа мобильного банка |
| **ВКонтакте (VK)** | `com.vkontakte.android` | Максимальная скорость видео и музыки напрямую |
| **Яндекс Go** | `ru.yandex.taxi` | Точная геолокация и быстрая подача такси |
| **Ozon** | `ru.ozon.app.android` | Стабильная оплата и загрузка карточек |
| **Wildberries** | `com.wildberries.ru` | Корректная работа каталога и оплаты |

5. Сохраните настройки и снова подключитесь к серверу.

## 3. Windows 11 — Умный DNS + ByeDPI/Zapret или полноценный VPN

На ПК с Windows 11 у вас есть два сценария использования Server-Combain: **лёгкий режим без VPN** (Умный DNS + ByeDPI/Zapret) и **полноценный VPN-клиент**.

### Вариант А. Умный DNS (DoH) + ByeDPI / Zapret (без полного VPN)
Идеален для повседневной работы за ПК: игры, российские сайты, банки и локальная сеть работают на полной скорости вашего провайдера без лишней задержки, а геоблокированные зарубежные сервисы (`OpenAI`, `Gemini`, `Claude`, `Copilot`, `Spotify`, `Autodesk` и др.) открываются прозрачно через ваш **AdGuard Home + SNIProxy**.

#### 1. Настройка зашифрованного DNS (DoH) в Windows 11
1. На сервере выполните `comb info` -> раздел **`1` (Умный DNS)** и скопируйте готовую команду PowerShell.
2. На Windows 11 откройте **PowerShell от имени Администратора** и выполните команду (подставив ваш IP и домен из `comb info`):
   ```powershell
   Add-DnsClientDohServerAddress -ServerAddress '203.0.113.10' -DohTemplate 'https://dns.vpn.example.com/dns-query' -AllowFallbackToUdp $False -AutoUpgrade $True; Clear-DnsClientCache
   ```
3. Откройте **Параметры Windows** -> **Сеть и Интернет** -> ваш активный адаптер (**Ethernet** или **Wi-Fi**) -> **Назначение DNS-сервера** -> **Изменить**:
   - Выберите **Вручную**, включите **IPv4**.
   - **Предпочитаемый DNS:** `203.0.113.10` (IP вашего сервера).
   - **DNS через HTTPS (DoH):** выберите **Вкл. (автоматический шаблон)**.
   - Поле «Дополнительный DNS» оставьте пустым (чтобы запросы не утекали к провайдеру).
   - Сохраните изменения.
4. *(Рекомендуется)* В браузере (Chrome / Edge / Firefox) отключите собственный встроенный «Безопасный DNS» (или укажите там тот же DoH URL `https://dns.vpn.example.com/dns-query`), чтобы браузер не обходил системный DNS Windows.

#### 2. Связка Умного DNS с ByeDPI или Zapret
- **Умный DNS (SNIProxy)** снимает **зарубежные геоблокировки** (когда сам сайт не пускает пользователей из РФ: ChatGPT, Gemini, Claude, Notion, Spotify и т. д.).
- **ByeDPI / Zapret** обходит **локальное DPI-замедление и блокировки ТСПУ** (YouTube, Discord и др.) без отправки всего трафика через зарубежный VPS.
- Вместе они закрывают 95% повседневных задач на ПК с минимальным пингом и без нагрузки на канал VPS.

> Подробное сравнение режимов «Умный DNS + ByeDPI/Zapret» и «Полный VPN» см. в [FAQ и решении проблем](faq_troubleshooting.md#2-умный-dns--byedpizapret-или-полноценный-vpn-что-выбрать).

### Вариант Б. Полноценный VPN на Windows 11
Нужен, когда требуется скрыть реальный IP, обойти жёсткие блокировки по IP или подключиться через **VK/Yandex CDN**.

Рекомендуемые клиенты для Windows:
- **`v2RayTun` (Windows)** — поддерживает JSON-подписку (`/u-json/<token>` или `/sub-json/<token>`) со встроенным RU-обходом и анти-ТСПУ фрагментацией.
- **`Throne` / `Nekoray`** — удобный десктопный клиент (импорт Base64-подписки `/u/<token>` или `/sub/<token>` через меню *Сервер -> Добавить профиль из буфера* или *Группы -> Новая группа -> Тип: Подписка*).
- **`Hiddify`** — минималистичный клиент с поддержкой режима TUN (импорт `/u/<token>` или `/sub/<token>`).
- **`AmneziaVPN`** — для протокола AmneziaWG 3.1 (см. [раздел 5](#5-amneziavpn-amneziawg-31--импорт-conf-vpn-и-qr)).

> **Примечание:** если на Windows вместо флажков стран (`🇩🇪`, `🇳🇱`, `🇺🇸`) отображаются буквы (`DE`, `NL`, `US`), это нормальная особенность шрифта Windows. Подробнее — в [FAQ](faq_troubleshooting.md#3-почему-на-windows-вместо-флагов-стран-показываются-буквы-us--de--nl).

## 4. iOS и macOS — VPN-клиенты и DoH-профиль

### VPN-клиенты для iPhone, iPad и Mac
Выберите один из клиентов в App Store:
- **`v2RayTun`** (iOS / macOS) — лучший выбор: нативно понимает JSON-подписки (`/u-json/<token>` и `/sub-json/<token>`) с RU-обходом и анти-ТСПУ фрагментацией.
- **`Streisand`** или **`FoXray`** (iOS / macOS) — импортируйте универсальную Base64-подписку (`https://vpn.example.com/u/<token>` или `https://vpn.example.com/sub/<token>`) либо отдельные ссылки `vless://` / QR-коды из `comb qr`.
- **`AmneziaVPN`** (iOS / macOS) — для подключения по AmneziaWG 3.1.

**Как добавить подписку в `v2RayTun` / `Streisand`:**
1. Скопируйте ссылку подписки или откройте сканер QR-кода (`+` -> *Import from clipboard* / *Scan QR*).
2. Разрешите iOS/macOS добавить VPN-конфигурацию (потребуется Face ID / Touch ID / пароль).
3. Обновите подписку, выберите узел **Combain-Direct-XHTTP** и включите туннель.

### Умный DNS (DoH-профиль) на iOS и macOS
Чтобы пользоваться Умным DNS без VPN на iPhone/iPad/Mac:
1. Создайте профиль конфигурации `.mobileconfig` с вашим DoH-адресом `https://dns.vpn.example.com/dns-query` (например, через генератор Apple DNS profile или приложение **AdGuard** / **DNSCloak** / **NextDNS-совместимый профиль**).
2. На **iOS**: откройте скачанный `.mobileconfig` -> **Настройки** -> **Профиль загружен** -> **Установить** -> затем перейдите в **Основные** -> **VPN и управление устройством** -> **DNS** и выберите установленный профиль.
3. На **macOS**: откройте `.mobileconfig` -> **Системные настройки** -> **Конфиденциальность и безопасность** -> **Профили** -> нажмите **Установить**.
4. Для Android 9+ также можно использовать **Частный DNS (DoT)** в системных настройках сети, указав просто домен: `dns.vpn.example.com` (работает по порту `853/tcp`).

## 5. AmneziaVPN (AmneziaWG 3.1) — импорт `.conf`, `vpn://` и QR

**AmneziaWG 3.1** (работает на сервере в официальном контейнере `combain-awg` с обфускацией `HeaderProtectionKey`, `S1–S4`, `H1–H4`, `I1`) — отличный быстрый UDP-туннель для игр, звонков и стабильной работы там, где UDP не режется. Внутри туннеля автоматически используется ваш локальный **AdGuard Home** (`10.8.1.1`).

### Где взять конфиг на сервере
- Профиль по умолчанию (`default`) создаётся автоматически при установке:
  - ссылка `vpn://...` выводится в `comb info` -> раздел **`3` (AmneziaWG)**;
  - QR-код выводится в `comb qr` -> пункт **`7` (AmneziaWG 3.1)**;
  - файлы лежат в `/etc/server-combain/clients/` (`awg_default.conf` и `awg_default.vpn`).
- Чтобы выдать отдельный профиль новому устройству (телефону, ноутбуку, роутеру):
  - запустите `comb` -> **`5` (Управление VPN и клиентами)** -> **`2` (Добавить клиента AmneziaWG)** -> введите имя (например, `phone`).

### Как подключиться в приложении `AmneziaVPN`
1. Скачайте актуальную версию **AmneziaVPN** (Windows, macOS, Linux, Android, iOS) с официального сайта или из магазина приложений.
2. Нажмите **«Приступим»** (или **`+`** в нижней панели):
   - **Способ 1 (самый быстрый — QR-код):** выберите **«QR-код»** и отсканируйте код из `comb qr` -> пункт `7`.
   - **Способ 2 (ссылка `vpn://`):** скопируйте строку `vpn://...` из `comb info` и выберите **«Текстовый ключ подключения»** -> вставьте строку -> **«Продолжить»** -> **«Подключиться»**.
   - **Способ 3 (файл `.conf`):** выберите **«Файл с настройками подключения»** и укажите файл `awg_<имя>.conf`.
3. Нажмите большую кнопку подключения — трафик и DNS сразу пойдут через туннель AWG 3.1.

## 6. Telegram Proxy — MTProto Fake-TLS и SOCKS5 в 1 клик

Server-Combain поднимает два независимых прокси для Telegram:
- **MTProto Fake-TLS (`combain-mtproto`)** — замаскирован под домен из белого списка; идеален для чатов, каналов, стикеров и загрузки медиа.
- **SOCKS5 с авторизацией (`combain-socks5`)** — рекомендуется для голосовых и видеозвонков в Telegram (MTProto не передаёт звонки).

### Подключение за 5 секунд
1. Администратор открывает `comb info` -> раздел **`4` (Telegram Proxy)** или `comb qr` -> пункты **`8` (MTProto)** / **`9` (SOCKS5)**.
2. На телефоне или ПК просто нажмите на веб-ссылку или отсканируйте QR-код:
   - MTProto: `https://t.me/proxy?server=203.0.113.10&port=18445&secret=<secret>` (или `tg://proxy?...`)
   - SOCKS5: `https://t.me/socks?server=203.0.113.10&port=10808&user=tguser&pass=<pass>` (или `tg://socks?...`)
3. Telegram откроет всплывающее окно с данными прокси — нажмите **«Подключить прокси»**.
4. *(Совет)* Можно добавить оба прокси сразу: MTProto оставить активным для переписки, а в настройках **Данные и память -> Прокси** при необходимости переключаться на SOCKS5 для звонков.
