# Локальная папка видео-котиков (`/cats/`)

Сюда можно положить любые свои короткие видеоролики или анимации (`.mp4`, `.webm`, `.gif`).
При запуске установки или обновлении сайта-заглушки (`combain` -> 5 -> 4) скрипт автоматически:
1. Скопирует все ваши файлы из этой папки на веб-сервер Nginx.
2. При необходимости докачает недостающие анимации до 10 штук.
3. Обновит `/cats/manifest.json`, чтобы режим **«Видео-котики»** в правом верхнем углу игры подхватывал их локально с вашего домена.
